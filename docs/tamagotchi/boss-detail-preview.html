Boss detail + Training dummy: confirm before coding

Part 1 is the edit plan. Part 2 is clickable example UI (hover the skill icons). All numbers are sample values; real ones come from the backend. Elements with a dashed outline are new.

Part 1: Edit details

Backend (demo-app-backend/src/modules/monster)

  • Shared helper (new, e.g. boss-detail.ts): builds { stats, defReductionPct, skills[], passive, dodge } from an IFighter plus the boss's arenaSkills/arenaPassive/arenaDodge and arena skill data (arena-data.ts). defReductionPct = min(DEF / (DEF + ARENA_DEFENSE_K), MAX_DEF_CUT/10000), base DEF only (no status effects).
  • world-boss.service.ts: add boss.detail to IWorldBossStatus.
  • raid.service.ts / raid-data.ts: add detail to IRaidBossInfo (skills once) and per-difficulty stats + defReductionPct to IRaidDifficultyInfo.
  • Dummy (new dummy.controller.ts + dummy.service.ts): GET /monster/dummy/presets and POST /monster/dummy/fight body { preset, def?, element?, bossRef? }. Runs the arena engine for the selected monster vs a non-attacking dummy. Follows the lock, tick, act, save order only for reading the monster. Writes nothing: no stamina, attempts, rewards or battle history. Returns the replay plus a summary (total damage, DPS, damage per hit, crits, DEF reduction %).
  • wiki.ts: publish dummy limits (fight time cap, huge HP value) so the guide never drifts.
  • Tests: helper unit tests (DEF % formula, cap), dummy service test (no persistence, deterministic with seeded rng).

Frontend (demo-app/src/pages/project/tamagotchi)

  • tamagotchi-interface.ts: add IBossDetail, IBossSkillView, dummy request/response types.
  • New BossDetail.tsx (stat grid, skill icons with hover tooltip) used by RaidPanel.tsx and WorldBossPanel.tsx. Raid also gets a 3-difficulty comparison table.
  • New DummyPanel.tsx; register 'dummy' (🎯 Training Dummy) in game-menu.ts and PageTamagotchi.tsx; reuse ArenaBattleModal for the replay.
  • tamagotchi-service.tsx: hooks useGetDummyPresets, useDummyFight. tamagotchi-helper.ts: formatters for stats, DEF %, skill tooltip text.
  • Required by project rule: Thai entry in patch-notes.ts; WikiPanel.tsx section for the dummy and boss stats; tests next to the new helpers and components.

Order

  1. Backend helper + tests
  2. Extend raid and world boss responses
  3. Dummy endpoint + tests
  4. Frontend BossDetail on both pages
  5. DummyPanel + menu
  6. Wiki, patch notes, final test run

Not touched: other modules, DB schema (no migration needed), reward or balance numbers.
