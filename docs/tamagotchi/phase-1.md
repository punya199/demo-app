# เฟส 1: V-Pet ออนไลน์

ภาพรวมทั้งหมดดูที่ [roadmap.md](./roadmap.md)

## ขอบเขต

**ทำในเฟสนี้**
- มอนผูกกับบัญชี (ต้อง login) มีมอนที่ยังมีชีวิตได้บัญชีละ 1 ตัว
- เลือกไข่ 1 ใน 3 สาย: 🔥 เพลิง / 💧 วารี / 🌿 พฤกษ์
- ค่าสถานะลดตามเวลา คำนวณที่เซิร์ฟเวอร์ แม้ปิดแอป
- การดูแล: ให้อาหาร, วิตามิน, ฝึก, เก็บอึ, ให้ยา, เปิด/ปิดไฟ
- Care mistake, ป่วย, ตาย, วิวัฒนาการแตกสายตามการเลี้ยง
- Hall of Fame: รายการมอนที่ตายไปแล้ว

**ยังไม่ทำ (เฟสถัดไป)**
- การต่อสู้ / แพ้ชนะ (มีคอลัมน์ `wins`, `losses` รอไว้แล้ว)
- มินิเกมการฝึก: เฟสนี้กดฝึกแล้วสำเร็จทันที (มี cooldown) เพราะผลจากมินิเกมฝั่ง client ปลอมได้
- โบนัสไข่ใบใหม่จากตัวก่อน, ไอเทม, เงิน, Fusion, push notification

## กติกา (backend `src/modules/monster/`)

ค่าทั้งหมดอยู่ใน `monster-rules.ts` และ `species-data.ts` ปรับได้ที่เดียว

### เวลา
- `tick(state, now)` จำลองทีละนาทีจาก `lastTickAt` ถึง `now` (จำกัดย้อนหลังสูงสุด 30 วัน)
- เรียกก่อนทุกการอ่านและทุก action ภายใน DB transaction ที่ล็อกแถวมอน (`pessimistic_write`)
- ไม่มี cron

### ค่าสถานะ
| ค่า | ช่วง | หมายเหตุ |
|---|---|---|
| ความอิ่ม (`fullness`) | 0–4 หัวใจ | ลดตามเวลา, ให้อาหาร +1 |
| ความแข็งแรง (`strength`) | 0–4 หัวใจ | ลดตามเวลา, วิตามิน/ฝึก +1 |
| น้ำหนัก (`weight`) | ≥ น้ำหนักขั้นต่ำของร่าง | อาหาร +1, วิตามิน +2, ฝึก −2 |
| อึ (`poops`) | 0–4 | เพิ่มตามเวลา, ครบ 4 กองแล้วป่วย |

ค่าหัวใจเก็บเป็นทศนิยม และแสดงผลด้วยการปัดขึ้น

**อัตราการลด (นาทีต่อ 1 หัวใจ) และรอบการอึ**

| ร่าง | ความอิ่ม | ความแข็งแรง | อึทุก |
|---|---|---|---|
| ร่างเด็ก 1 | 10 | 10 | 30 นาที |
| ร่างเด็ก 2 | 30 | 30 | 60 นาที |
| ร่างโต | 60 | 75 | 120 นาที |
| ร่างสมบูรณ์ | 75 | 90 | 120 นาที |
| ร่างสูงสุด | 90 | 100 | 120 นาที |

### การนอน
- ตารางคงที่ตามเวลาไทย: นอน 22:00–07:00
- ระหว่างนอน ความอิ่ม/ความแข็งแรงไม่ลด และไม่อึ
- ถ้าเปิดไฟค้างไว้ 30 นาทีหลังมอนหลับ นับเป็น care mistake 1 ครั้งต่อคืน
- ตื่นแล้วไฟเปิดเอง
- ระหว่างนอนให้อาหาร, วิตามิน และฝึกไม่ได้

### Care mistake
- ความอิ่มเป็น 0 ครบ 30 นาที นับ 1 ครั้ง จากนั้นนับเพิ่มทุก 4 ชั่วโมงที่ยังเป็น 0
- ความแข็งแรงเป็น 0 ใช้กติกาเดียวกัน
- เปิดไฟตอนนอน (ข้างบน)
- นับใหม่ทุกครั้งที่วิวัฒนาการ

### ป่วยและตาย
- **ป่วยเมื่อ:** อึครบ 4 กอง หรือหิว (ความอิ่ม 0) ต่อเนื่อง 6 ชั่วโมง
- **ระหว่างป่วย:** ฝึกไม่ได้ ให้ยาเพื่อรักษา
- **ตายเมื่อ:**
  - ป่วยไม่รักษา 12 ชั่วโมง
  - หิวต่อเนื่อง 24 ชั่วโมง
  - อายุครบ 10 วัน (นับจากฟัก)

### วิวัฒนาการ
| ร่าง | อยู่นาน |
|---|---|
| ไข่ | 5 นาที |
| ร่างเด็ก 1 | 1 ชั่วโมง |
| ร่างเด็ก 2 | 12 ชั่วโมง |
| ร่างโต | 36 ชั่วโมง |
| ร่างสมบูรณ์ | 72 ชั่วโมง (ถ้าไม่ผ่านเงื่อนไข จะอยู่ร่างนี้ไปจนตาย) |
| ร่างสูงสุด | จนอายุขัยหมด |

เมื่อครบเวลา เลือกร่างถัดไปจากรายการ `evolutions` ของสายพันธุ์ตามลำดับ ร่างแรกที่เงื่อนไขผ่านคือร่างที่ได้

| จาก | ไป | เงื่อนไข (นับในร่างปัจจุบัน) |
|---|---|---|
| ร่างเด็ก 2 | ร่างโต (ดี) | care mistake ≤ 3 |
| ร่างเด็ก 2 | ร่างโต (ดื้อ) | อื่น ๆ |
| ร่างโต (ดี) | ร่างสมบูรณ์ (ดี) | care mistake ≤ 2 และฝึก ≥ 8 |
| ร่างโต (ดื้อ) | ร่างสมบูรณ์ (ดี) | care mistake ≤ 1 และฝึก ≥ 12 |
| ร่างโต (ทุกแบบ) | ร่างสมบูรณ์ (ขี้เกียจ) | อื่น ๆ |
| ร่างสมบูรณ์ (ดี) | ร่างสูงสุด | care mistake ≤ 1 และฝึก ≥ 12 |

### Action
| `type` | ผล | ใช้ไม่ได้เมื่อ |
|---|---|---|
| `feed` | ความอิ่ม +1, น้ำหนัก +1 | ไข่, หลับ |
| `vitamin` | ความแข็งแรง +1, น้ำหนัก +2 | ไข่, หลับ |
| `train` | ความแข็งแรง +1, น้ำหนัก −2, ฝึก +1, cooldown 60 วินาที | ไข่, หลับ, ป่วย |
| `clean` | อึ = 0 | ไข่ |
| `medicine` | หายป่วย | ไม่ได้ป่วย |
| `lights` | สลับเปิด/ปิดไฟ | ไข่ |

ทุก action ใช้ไม่ได้เมื่อมอนตายแล้ว

## API

ทุก route ใช้ `@AuthUser()`

| Method | Path | Body | ผล |
|---|---|---|---|
| GET | `/monster/me` | – | `{ monster: IMonsterView \| null }` มอนตัวล่าสุด (ยังมีชีวิตหรือตายแล้ว) |
| POST | `/monster/hatch` | `{ line: 'flame' \| 'tide' \| 'leaf' }` | รับไข่ใบใหม่ (ห้ามถ้ายังมีตัวที่มีชีวิต) |
| POST | `/monster/action` | `{ type }` | ทำ action แล้วคืน `{ monster }` |
| GET | `/monster/history` | – | `{ monsters: IMonsterView[] }` มอนที่ตายแล้ว ล่าสุดก่อน |

`IMonsterView` คือข้อมูลในตาราง + ข้อมูลสายพันธุ์ (`name`, `emoji`) + `isSleeping` (คำนวณจากเวลา) + `trainReadyAt` (เวลาที่ฝึกได้อีกครั้ง)

## ข้อมูล

```
monsters      { id, owner_id, line, species_id, stage, fullness, strength, weight, poops,
                is_sick, lights_on, care_mistakes, train_count, wins, losses,
                poop_minutes, hungry_minutes, weak_minutes, sick_minutes, sleep_light_minutes,
                stage_minutes, age_minutes, born_at, last_tick_at, last_trained_at,
                died_at, death_cause, + คอลัมน์ audit ของ BaseModelEntity }
monster_logs  { id, monster_id, type, payload jsonb, + audit }
```

- unique index `owner_id` เมื่อ `died_at IS NULL AND deleted_at IS NULL` (มอนที่มีชีวิตได้ 1 ตัว)
- log type: `hatch`, `action`, `evolve`, `care_mistake`, `sick`, `death`
