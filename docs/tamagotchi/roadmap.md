# Monster V-Pet: ฟีเจอร์และ Roadmap

เกมเลี้ยงมอนสเตอร์ดิจิทัลแนว V-Pet ที่ผลการเลี้ยงและการต่อสู้กำหนดเส้นทางวิวัฒนาการ ต่อยอดไปสู่ PvP, World Boss และ Party Boss Raid พร้อมระบบเงิน ไอเทม ชุดเซ็ต ตีบวก และเช่าตัวเพื่อน

> มอนสเตอร์ ชื่อ ธาตุ ศัพท์ และภาพในเกมออกแบบเองทั้งหมด ใช้แนวเกม V-Pet เป็นแรงบันดาลใจเท่านั้น

แผนละเอียดแต่ละเฟส: [phase-1.md](./phase-1.md) (เสร็จแล้ว) · [phase-2.md](./phase-2.md) (เสร็จแล้ว: 2a, 2b, 2c) · [phase-3.md](./phase-3.md) (เสร็จแล้ว: 3a, 3b)

## หลักการออกแบบ

- **ออนไลน์ตั้งแต่เฟส 1 (server-authoritative):** มอนผูกกับบัญชีผู้ใช้ (ใช้ login เดิมของแอป) กติกาทั้งหมดคำนวณที่ `demo-app-backend` ไม่มีข้อมูลเกมใน localStorage
- **Frontend แสดงผลอย่างเดียว:** ส่ง action ไปเซิร์ฟเวอร์ แล้วแสดง state ที่ได้กลับมา ไม่มีกติกาเกมฝั่ง frontend
- **Battle engine เป็น pure function บนเซิร์ฟเวอร์:** `simulateBattle(teamA, teamB, seed)` ใช้ seeded RNG ได้ผลเดิมทุกครั้ง เซิร์ฟเวอร์ส่ง event log กลับมา frontend เล่น animation ตาม log จึงไม่ต้องแชร์โค้ดระหว่างสอง repo
- **Data-driven:** สายพันธุ์ เงื่อนไขวิวัฒนาการ ไอเทม เซ็ต และบอส เป็นข้อมูล config เพิ่มเนื้อหาได้โดยไม่ต้องแก้โค้ด
- **การสุ่มที่มีมูลค่าทำบนเซิร์ฟเวอร์เสมอ:** ดรอป ตีบวก ผลต่อสู้ พร้อมบันทึก log ทุกครั้ง

## ฟีเจอร์เมื่อทำครบ

### 1. เลี้ยงมอน (V-Pet)
- วงจรชีวิต: ไข่ → ร่างเด็ก 1 → ร่างเด็ก 2 → ร่างโต → ร่างสมบูรณ์ → ร่างสูงสุด
- ค่าการเลี้ยง: ความอิ่ม, ความแข็งแรง, stamina, น้ำหนัก, ความสะอาด (อึ) — ไม่มีระบบนอน มอนตื่นตลอด
- การดูแล: ให้อาหาร, วิตามิน, ให้ยา, เก็บอึ, ฝึก, มินิเกมเติม stamina
- ออนไลน์ (เปิดเกมค้างไว้): วิวัฒนาการเร็วขึ้น x2 และ stamina ลดช้าลงครึ่งหนึ่ง
- คู่มือในเกม (Wiki) อธิบายกติกาและสูตรทั้งหมด ตัวเลขดึงจากเซิร์ฟเวอร์
- Care Mistake มีผลต่อการวิวัฒนาการ
- เวลาเดินแม้ปิดแอป (เซิร์ฟเวอร์คำนวณย้อนหลังจาก `lastTickAt`)
- ป่วย / อายุขัย / ตาย, Hall of Fame
- ต้นไม้วิวัฒนาการแตกสาย และร่างลับที่ต้องใช้ไอเทม
- Fusion: รวมมอนสองตัวจากผู้เล่นสองคน

### 2. ระบบต่อสู้
- ค่าพลัง HP / ATK / DEF / SPD
- ธาตุสามเส้า: 🔥 เพลิง > 🌿 พฤกษ์ > 💧 วารี > 🔥 เพลิง
- สกิล 2–4 ท่าต่อร่าง, เทิร์นเบส (auto หรือเลือกท่าเอง)
- บทบาท: แทงก์ / ดาเมจ / ซัพพอร์ต ตามสายวิวัฒนาการ
- โบนัสเซ็ตคำนวณจากอุปกรณ์ที่ใส่ทุกครั้ง

### 3. PvE
- โหมดผจญภัยแบ่งด่าน มีบอสท้ายด่าน
- สถิติแพ้/ชนะใช้เป็นเงื่อนไขวิวัฒนาการ
- Dex สะสมร่างที่เคยเลี้ยงสำเร็จ

### 4. เศรษฐกิจ

| สกุล | ได้จาก | ใช้ทำอะไร |
|---|---|---|
| 🪙 Coin | PvE, daily quest, ขายไอเทม, ค่าเช่าตัว | ร้านค้า, ค่าตีบวก, ค่าเช่าตัว |
| 💎 เพชร (มีแล้วในเฟส 2a) | ชนะบอสครั้งแรก, ค้นพบร่างใหม่ใน Dex | เติม stamina |
| 🎖️ Raid Token | Boss Raid, อันดับ PvP | วัตถุดิบขั้นสูง, ไอเทมลับ, ใบกันแตก |
| 🎫 Boss Token | ชนะบอสแต่ละตัว | แลกชิ้นเซ็ตที่ต้องการ |

- ไม่ผูกกับเงินจริง, ออกแบบ source/sink ให้สมดุล
- `wallet` + `wallet_transaction` บันทึกทุกรายการ ตัดเงินใน DB transaction + row lock

### 5. ไอเทมและอุปกรณ์
- ประเภท: ของกิน/ใช้, ไอเทมวิวัฒนาการ, วัตถุดิบ, อุปกรณ์
- อุปกรณ์ 4 ช่อง: อาวุธ · เกราะ · หมวก · เครื่องประดับ (เซ็ต 2/4 ชิ้น, ผสม 2+2 ได้)
- เกรด: ธรรมดา → หายาก → มหากาพย์ → ตำนาน
- อุปกรณ์ส่งต่อให้มอนตัวใหม่ได้เมื่อตัวเก่าตาย

| | ไอเทมธรรมดา | ชุดเซ็ต |
|---|---|---|
| ได้จาก | PvE, ร้านค้า, กล่องสุ่ม | ดรอปจากบอสประจำเซ็ตเท่านั้น |
| ค่ารอง | สุ่ม 1–3 ค่า | ค่าตายตัว |
| ความพิเศษ | หาง่าย อาจสุ่มได้ดีมาก | โบนัสเซ็ต 2/4 ชิ้น, แรงขึ้นที่ +10 |

### 6. ชุดเซ็ตประจำบอส

| บอส | เซ็ต | 2 ชิ้น | 4 ชิ้น |
|---|---|---|---|
| 🔥 ราชันย์ลาวา | ชุดเพลิงกัลป์ | ATK +15% | ท่าธาตุเพลิงติดเผาไหม้ 3 เทิร์น |
| 💧 อสูรห้วงลึก | ชุดวารีพิทักษ์ | DEF +20% | เริ่มด้วยโล่ 15% ของ HP |
| 🌿 พฤกษาโบราณ | ชุดรากแก้ว | HP +20% | ฟื้น HP 5% ทุกเทิร์น |
| ⚡ จักรกลพายุ (World) | ชุดสายฟ้าเร็ว | SPD +15% | 20% โจมตีซ้ำ |
| 👑 บอส Party Raid | ชุดผู้นำทัพ | ทั้งปาร์ตี้ ATK +5% | ชุบชีวิตเพื่อน 1 ครั้ง |

- ชนะ 1 ครั้งได้ 1 ชิ้น (สุ่มช่อง 25%), Normal/Hard/Nightmare ได้เกรดหายาก/มหากาพย์/ตำนาน
- Boss Token แลกชิ้นที่ต้องการได้โดยตรง, ชิ้นซ้ำแยกเป็นวัตถุดิบ

### 7. ตีบวก (ที่อุปกรณ์ ไม่ใช่ตัวมอน)

| ระดับ | อัตราสำเร็จ | ถ้าล้มเหลว |
|---|---|---|
| +1 ถึง +5 | 100% | – |
| +6 ถึง +9 | 80% → 50% | เสียวัตถุดิบ |
| +10 ถึง +12 | 40% → 20% | ระดับลด 1 |
| +13 ถึง +15 | 15% → 5% | ระดับลด หรือแตก |

- Pity, แสดงอัตราจริง, ใบกันแตก, โบนัสทุก 5 ระดับ, บันทึก `enhance_log`

### 8. PvP
- Async: สู้กับ snapshot ของผู้เล่นอื่น, ELO, ซีซันรายเดือน
- Realtime: ท้าเพื่อนสดผ่าน WebSocket
- ห้ามใช้ตัวเช่า

### 9. Boss Raid
- บอสประจำธาตุ Normal / Hard / Nightmare
- World Boss: HP รวมทั้งเซิร์ฟเวอร์, ตีวันละ N ครั้ง, อันดับดาเมจ
- บอสหมุนเวียนรายสัปดาห์, เพิ่มบอส/เซ็ตทุกซีซันผ่าน config

### 10. Party Boss Raid (Realtime)
- ปาร์ตี้ 2–4 คน, lobby, บอสหลายเฟส, reconnect
- เซ็ตซัพพอร์ตเฉพาะ Raid, เติมช่องว่างด้วยตัวเช่า

### 11. Social และการเช่าตัว
- ระบบเพื่อน, เยี่ยมมอน, ส่งของขวัญ
- ตั้งตัวซัพพอร์ต (snapshot) ให้คนอื่นเช่า ได้ Coin + แต้มมิตรภาพ, มีเพดานรายได้ต่อวัน
- ผู้เช่าใช้ได้ปาร์ตี้ละ 1 ตัว, AI ควบคุม, ไม่ได้ EXP/รางวัล
- ใช้ได้ใน World Boss และ Party Raid, ใช้ใน PvP ไม่ได้

### 12. อื่น ๆ
- Event ตามเทศกาล, Push notification (PWA)

### 13. โหมด Idle

**Idle ออฟไลน์: ส่งมอนออกสำรวจ**
- กดส่งมอนออกสำรวจ แล้วปิดแอปได้ มอนเก็บ Coin, วัตถุดิบ และ EXP ตามเวลาที่ผ่านไป
- ปริมาณรางวัลขึ้นกับค่าพลังของมอนและพื้นที่ที่เลือก
- สะสมได้สูงสุด 8 ชั่วโมง (ขยายเป็น 12 ชั่วโมงได้ภายหลัง เช่นผ่านไอเทม) ต้องกลับมากดรับ
- **ทำแล้วในเฟส 2c:** จ่ายเหรียญ + ไอเทมสะสมจากคลัง · **เฟส 3 เพิ่มหินตีบวก** (1 ก้อน/ชม.) เป็นวัตถุดิบจากสำรวจ ส่วน EXP ยังไม่มีในเกม
- ระหว่างสำรวจ ความอิ่มและความแข็งแรงยังลด แต่ช้าลงครึ่งหนึ่ง ยังต้องกลับมาดูแล (อึไม่เพิ่ม และสู้ในผจญภัยไม่ได้)
- ถ้ามอนป่วย หรือความอิ่มเป็น 0 มอนจะกลับบ้านเองและหยุดเก็บรางวัล
- เรียกกลับได้ทุกเมื่อ ตอนกลับเข้าแอปแสดงสรุป "ระหว่างที่คุณไม่อยู่ ได้..."
- ใช้การคำนวณย้อนหลังแบบเดียวกับ `tick()` ที่มีอยู่แล้ว

**Idle ออนไลน์: ต่อสู้อัตโนมัติ**
- เปิดหน้าทิ้งไว้ มอนสู้ด่าน PvE วนไปเรื่อย ๆ หน้าจอเล่น animation จาก event log ของเซิร์ฟเวอร์
- ทำแล้วในเฟส 2c: สู้ได้เฉพาะด่านที่ชนะเองแล้วและไม่ใช่บอส ใช้ stamina น้อยลง จ่ายรางวัลเป็นสัดส่วนของด่าน
- รางวัลต่อชั่วโมงมากกว่าแบบออฟไลน์เล็กน้อย เป็นแรงจูงใจให้เปิดเกมไว้

**กันโกง**
- เซิร์ฟเวอร์คำนวณรางวัลจากเวลาจริงเท่านั้น client ขอรางวัลเกินเวลาที่ผ่านไปไม่ได้
- ต่อสู้อัตโนมัติจำกัดจำนวนรอบต่อนาที (cooldown 60 วินาที) และมีเพดานรางวัลต่อวัน (1,500 เหรียญ) กันสคริปต์ปั๊มของ

## Roadmap

| เฟส | เนื้อหา | งาน backend หลัก | Realtime |
|---|---|---|---|
| 1 ✅ | V-Pet ออนไลน์ | `monster` | – |
| 2a ✅ | ต่อสู้ PvE (ผจญภัย 3 พื้นที่) + กระเป๋าเงิน (Coin, เพชร) + Dex + ร้านค้าแบบใช้ทันที + stamina + มินิเกม + คู่มือ + ลบระบบนอน | `monster` (battle, adventure, shop), `wallet` | – |
| 2b ✅ | คลังไอเทม + daily quest | `inventory`, `quest` (ในโมดูล `monster`) | – |
| 2c ✅ | โหมด Idle (สำรวจออฟไลน์, ต่อสู้อัตโนมัติออนไลน์) | `expedition` (ในโมดูล `monster`) | – |
| 3 ✅ | อุปกรณ์ 4 ช่อง + ตีบวก (มี `setId` ตั้งแต่ตอนนี้) | `equipment`, `enhance` (ในโมดูล `monster`) | – |
| 4 | Async PvP | ladder, ELO | – |
| 5 | World Boss + ชุดเซ็ต + ระบบเพื่อน + เช่าตัว | `raid`, `friend` | – |
| 6 | Realtime PvP | WebSocket gateway | ✓ |
| 7 | Party Boss Raid | lobby, room state | ✓ |
