# ปรับ UI และ stamina ผจญภัย

ต่อจาก [roadmap.md](./roadmap.md) หัวข้อ "ปรับปรุงภายหลังเฟส 5" · ข้อเสนอพร้อมภาพจำลองอยู่ใน artifact "Monster Update Plan"

## 1. Stamina สำหรับผจญภัย

- **แยกต่อตัว:** มอนแต่ละตัวมี stamina 0–100 (คอลัมน์ `monsters.stamina`) ไข่ใหม่และร่างรวมเริ่มที่ 100
- **ใช้กับผจญภัยเท่านั้น:** สู้เองและสู้อัตโนมัติ ครั้งละ 10 (`ADVENTURE_STAMINA_COST`)
  - stamina ไม่ถึง 10 สู้ผจญภัยไม่ได้ (`Not enough stamina`)
  - บอส, บอสโลก, สนามประลอง และการสำรวจ ไม่ใช้ stamina
- **ฟื้นเอง:** +10 ต่อชั่วโมง (`STAMINA_REGEN_PER_HOUR`) · ออนไลน์ฟื้นเร็วขึ้น x2 (`ONLINE_STAMINA_REGEN_MULTIPLIER`)
  - คิดทีละนาทีใน `tick()` เหมือนค่าอื่น ระหว่างเป็นไข่ไม่เปลี่ยน
- **เติม:**
  - มินิเกม (`POST /monster/minigame { hits, monsterId? }`): หยุดแถบ 3 รอบ ได้ +10 / +15 / +20 / +30 ตามจำนวนที่โดน เล่นได้ทุก 5 นาที
  - 💎 5 เติมเต็ม (`POST /monster/stamina/refill { monsterId? }`) เต็มอยู่แล้วจะปฏิเสธ และตรวจกติกาก่อนตัดเพชร
- **หน้าจอ:** การ์ด stamina บนหน้าผจญภัย (เหลือสู้ได้กี่ครั้ง, เวลาที่จะเต็ม, ปุ่มมินิเกมและเติม) และ ⚡ ในแถบตัวที่เลือกอยู่
- ตัวเลขทั้งหมดอยู่ใน `monster-rules.ts` และแสดงในคู่มือหัวข้อ "Stamina (ผจญภัย)"

## 2. แถบตัวที่เลือกอยู่

- อยู่บนทุกเมนู บนมือถือติดด้านบนเมื่อเลื่อน บนจอใหญ่อยู่คอลัมน์ซ้าย
- แสดงรูป, ชื่อ, ร่าง, ธาตุ, หัวใจ, stamina, ป่วย/ออกสำรวจ
- ปุ่ม "เปลี่ยน" กางช่องมอน 4 ช่อง (ย้ายมาจากหน้าเลี้ยง) ช่องว่างกดเพื่อรับไข่ใหม่

## 3–4. ต้นไม้วิวัฒนาการ

- `evolution-tree.ts` (pure) จัดตำแหน่ง: คอลัมน์ละร่าง · สาย Alt บน, สายดี/ปกติกลาง, สายดื้อ/ขี้เกียจล่าง · ทำเครื่องหมาย "ทางตัน" ให้ร่างที่ไม่ใช่ร่างสุดท้ายและไปต่อไม่ได้
- `EvolutionTree.tsx` วาดเป็น SVG ใช้ร่วมกันสองที่:
  - **ปุ่ม "🌳 สายวิวัฒนาการ"** ในหน้าเลี้ยง เปิด `EvolutionTreeModal` ของตัวที่เลือก: ทางที่ผ่านมา (เขียว), ร่างปัจจุบัน, ขั้นถัดไป (เส้นประ), ทางตัน (แดง) และเงื่อนไขพร้อมความคืบหน้า แสดงชื่อทุกร่าง ไม่ซ่อน
  - **คู่มือ → วิวัฒนาการ:** เลือกสายจากชิป 8 ธาตุ กดที่ร่างเพื่อดูค่าพลัง สกิล ทางเข้าและทางออก
- `GET /monster/:monsterId/evolution-path` คืนร่างที่ตัวนั้นเคยเป็น ไล่ตาม log `evolve` จาก `from` → `to` (ไม่เรียงตามเวลา เพราะวิวัฒนาการหลายขั้นใน tick เดียวมีเวลาเดียวกัน)

## 5–6. เมนูและ responsive

- เมนู 14 รายการเป็นตาราง แบ่ง 3 กลุ่ม (ดูแล / ต่อสู้ / อื่น ๆ) แทนแท็บแนวนอน (`game-menu.ts`)
- เมนูที่เปิดอยู่เก็บใน URL hash เช่น `/monster#adventure` โหลดใหม่แล้วอยู่ที่เดิม
- มือถือ: 1 คอลัมน์ เมนู 5 ช่องต่อแถว · จอ ≥ 1024px: คอลัมน์ซ้าย 300px (แถบตัวที่เลือก + เมนู ติดอยู่กับที่) และเนื้อหาด้านขวา กว้างสุด 1,152px
- ตรวจที่ความกว้าง 390 และ 1280px: ไม่มีการเลื่อนแนวนอน ต้นไม้เลื่อนเฉพาะในกล่อง และเลื่อนไปที่ร่างปัจจุบันเอง

## 7. อุปกรณ์ไม่แชร์ + แยกประเภท

- ชิ้นหนึ่งใส่ได้ทีละตัว: `POST /equipment/equip` ปฏิเสธชิ้นที่ตัวอื่นใส่อยู่ (`Equipment is worn by another monster`) เว้นแต่ส่ง `move: true`
- หน้าจอ: ชิ้นที่ตัวอื่นใส่แสดง "ใส่อยู่กับ ..." และปุ่ม **"ย้ายมาใส่ตัวนี้"** ที่ถามยืนยันก่อน ("ถอดจาก A แล้วใส่ให้ B")
- กระเป๋ามีแท็บ ทั้งหมด / อาวุธ / เกราะ / หมวก / เครื่องประดับ (พร้อมจำนวน) และตัวกรอง "เฉพาะชิ้นที่ยังไม่มีใครใส่" เรียงตามเกรดแล้วระดับบวก
- กดช่องว่างของตัวที่เลือก เปิดกระเป๋าที่แท็บของช่องนั้น
