# 13: Cores and elements

**What to build:** Four elements (Fire, Ice, Nature, Physical) with elemental advantage. The player has 4 core slots; equipping a core activates its elemental power, and cores can be promoted through rarity tiers.

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] Elemental advantage changes damage in battle and in the server replay
- [ ] A core can be equipped in any of the 4 slots and its power activates
- [ ] Core promotion spends the configured materials and raises rarity
- [ ] Elemental balance is covered by golden-replay tests
