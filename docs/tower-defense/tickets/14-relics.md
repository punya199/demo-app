# 14: Relics

**What to build:** Relics unlock exclusive skills for core heroes. Unlocking a relic adds that skill to the hero's draft pool and its effects apply in battle.

**Blocked by:** 13

**Status:** ready-for-agent

- [ ] A relic can be unlocked for its matching core hero
- [ ] The exclusive skill appears in the draft and works in battle
- [ ] The server replay reflects the unlocked relic
- [ ] An unlock without the required hero is rejected
